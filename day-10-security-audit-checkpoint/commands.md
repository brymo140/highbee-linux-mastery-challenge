find / -perm /4000 (SUID audit): This command scans the entire computer starting at the root directory (/) to locate files with SUID (Sey USer ID) bit enabled.
last: This command is used to get the information of the history of all user logins and logouts from the system's background login database  including when the system is rebooted. it scans bacward in time starting from the present moment.  
lastlog: This command is used to check for the most recent login times in a neat table format for every  single uder configured on the system, odered by their User ID (UID). 
w: This command provides a highly detailed, real-time snapshot of the syetem. It shows exactly who is currently logged in, ther terminal type, their remote ip address, the time they connected, how long they have been idle, and crucially the exact command they are typing now. This can obviously be used in many ways, ethically or unethically. 
who:This command is a lighter version of "w" as it simply prints a clean list of users currently logged into the system, along with their terminal names and login timestamps. 
groups: This command prints the names of all the security groups that your current user account belongs to. It can also append to a username (e.g., groups highbee) to check another user's group assignments.
passwd: This is fortunately the command that allosws a user to change the surrent user account password. It can also be run by the administrator or with the administrative privilege if they want to change a password for another user account. 
chage -l:This command is the one used to list the complete password aging and expiration details for a specific user account. It displays precisely when the password was last changed, when it is scheduled to expire, and when the account itself will become inactive.
lastb: This command is like "last" but it only scanns for and lists all failed login attemps.This is very useful for spotting brute-force hacking attacks targeting the machine.
history | grep sudo: This comand is the one that searches through the current terminal's shell history file to pull up every line where "sudo" has been used. This is also very usefull when you want to seeacjh for anything that has been typed in the current terminal, just remove the sudo there since this one is to search for anywhere you have typed sudo in the current terminal opened and add any command you want to search what you have used it for. For example, "history | grep ll" or anything else you want is the space of 'll' or 'sudo'.
