- ps aux: It displays a detailed, complete snapshot of every single running process on the system. (a) Shows processes for all users. (u) Displays user-oriented information (like CPU and memory percentage usage). (x) Includes processes not attached to a terminal (like background system services).
- ps -ef: This is an alternative way to list every running process using standard system format. The -e selects all processes, and -f generates a full-format listing. It explicitly shows the PPID (Parent Process ID), making it easy to see which application spawned another one.
- ps -u <username>: This will filter the process snapshot to display only the active programs running under a specific user account (e.g., ps -u highbee). 
- top: It opens a real-time, interactive table that automatically updates every few seconds. It displays global system health (CPU usage, memory usage, uptime) at the top, followed by a live list of the most resource-heavy processes sorted by CPU usage. Typing q will make you exit the live snapshot mode.
- htop: A heavily modernized, text-graphical replacement for top. It uses color-coded bars to visualize individual CPU core workloads, memory usage, and swap space. It allows you to scroll vertically and horizontally through tasks, search for programs, and manage processes using your keyboard. (Must be installed via apt or dnf on some systems).
- pgrep: This in short for Process Grep. Instead of typing ps aux | grep nginx, you run pgrep nginx to instantly look up and output only the numeric Process IDs (PIDs) matching that application name.
- pstree: This visualizes all running processes as a graphical tree structure diagram. It shows the hierarchical lineage of your system, illustrating exactly which parent services spawned which child background workers.
- lsof -i: It stands for List Open Files. The -i flag narrows the search to network connections. It shows you a live mapping of every single application currently listening to or communicating over a network port (e.g., seeing exactly which process is occupying port 80 or 8080).
- jobs: It will list all active tasks that you have paused or pushed into the background inside your current terminal window session (e.g., when you hit Ctrl + Z to temporarily freeze a running script).
- nice/renice: Controls a process's "Niceness" value, which dictates its CPU scheduling priority. Niceness scales from -20 (highest priority, least nice to other programs) to 19 (lowest priority, very nice to other programs). "nice -n <value> <command>" launches a brand-new program with a preset priority tier (e.g., nice -n 10 tar -czf backup.tar.gz /data runs a heavy compression job quietly in the background so it doesn't slow down your computer). "renice <value> -p <PID>" changes the scheduling priority of an already running process on the fly using its PID. Note that only administrative users (sudo) can assign negative values to speed up a process.
