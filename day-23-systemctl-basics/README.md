## What I practiced
I practiced on commands that form the core framework for managing system services, background workers, and daemons using systemd, the modern initialization and service manager used by almost all major Linux distributions (including Ubuntu, Debian, Fedora, CentOS, and Red Hat). While commands like bg or nohup that i learned yesterday (day 22) handle scripts inside your immediate user session, systemctl interacts directly with the operating system kernel to control system-wide, permanent background applications (called units or services, such as nginx, ssh, or docker).
