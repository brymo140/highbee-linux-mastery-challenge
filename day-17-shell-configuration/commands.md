- nano ~/.bashrc: It openes the standard Bash configuration file for your individual user account using the nano text editor. Any "export" commands, configurations, or custom shortcuts added here will load automatically every time you open a new interactive terminal window. 
- source ~/.bashrc: It will reload he '.bashrc' file immediately inside your current terminal window. This saves you from having to close and restart your terminal window. So, there will no be need to always close your current terminal application just to apply a settings or alias you newly added to the file. 
- cat ~/.bash_profile: This will display the user-specific startup profile configuration file. While .bashrc runs for every new terminal window, .bash_profile (or .profile on some systems) runs only once when you first physically log into the computer (like over an SSH network connection).
- sudo nano /etc/environment: It opens the system-wide environment file with administrator privileges. Settings saved here apply globally across the entire computer for all users, system services, and background tasks. It only accepts pure KEY="VALUE" assignments (no export or shell script code).
- sudo nano /etc/bash.bashrc: This one opens the system-wide Bash configuration file. Unlike /etc/environment, this is a fully functional shell script that runs globally for every user on the machine the moment they open a Bash terminal.
- alias: If this command is run y itself wih no arguments, it rpints out a clean list of every single command shortcut that has been made in your current session. But if the alias has an argument (e.g., alias name="command") = (alias edit="nano") which will let you type just edit to be able to "edit" any file that has the permission to write. 
- unalias: This will delete or undo a specific command shortcut from your crrent session's active memory. (e.g., unalias edit)
- type: This will tell you how the system exactly interpretes the command specified. It will tel you in detail whether a word is a built-in shell function, a custom alias, or a physical binary file sitting on your hard drive.
- which: It scans through the folders listed on your active $PATH and prints out the exact absolute path to the executable file that runs when you type the command (e.g., which python3 outputs /usr/bin/python3). If the command is an alias or built-in, it often prints nothing.
- whereis: This is a broader search tool. Instead of just searching your $PATH, it checks standard system directories to return the locations of the program's binary execution file, its source code files, and its built-in manual documentation pages (man pages) all at once.
