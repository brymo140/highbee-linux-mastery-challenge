## What I practiced
Today's commands are the RHEL and Fedora family equivalent of what I already covered with apt on Day 13, plus a few universal install tools like snap, dpkg -i, and pip/npm. Since I'm working on Ubuntu, I ran the Ubuntu-native tools directly and understood dnf, yum, and rpm by comparing their syntax and purpose to apt, install, remove, and search, which I already know well from yesterday.

## What surprised me
What stood out is how similar the actual concepts are across different Linux distributions, even when the exact command name changes. apt and dnf are really solving the same problem with different syntax, which makes switching between Ubuntu and something like Amazon Linux far less intimidating than I expected.
