## What I practiced

I practiced with different commands to read the file permission details using "ls -l" and set the permissons using diffrent varieties of  "chmod" and even be able to get the  specific metadata for files and folders like the permission details, the username of the owner and the group at once using "stat -c '%A %U %G'".  

## What surprised me
What surprises me is how versatile ways of changing file and folder permissions are and they have different reasons to exist.
