ls -l (permission string): it allows us to read the file metadata and permissions.
chmod (relative +/-): Using this allows us to be able to add or remove specific permissions without changing the rest. Examples is when we run "chmod +x file.sh", it allows us to assign or add execute permission to everyone. Everyone means the user, group, and others. Another example is "chmod g-w file.txs" which allows us to remove the write permission for the group tier.
chmod (assignment =): Instead of removing or adding permissions rights, this one sets the exam permission for a tier and completely overwright whaterver was there before. Example: "chmod u=rw,g=r,o=" and this means, assigning read and write to user, read to group and nothing or block others to have any permission on the file or folder.
chmod 755 (octal): since we have three tiers, the octa method used used numbers to set the permissons on each tier as each digit represents each tier. The first one id for the user, the second one for the group and the third digit is for other tier. Each permission has a numeric value: Read=4, Write=2, Execute=1. adding all together which means giving all permissions get 7 and if you add 2 and 1 which gives you 3 means you only allow write and execute. the same logic for any assignment.  Running "chmod 755" means you allow all permissons for the user and read and execute for the group tier and read and execute also for the other tier. i.e.(rwxr-xr-x).
chmod 644 (octal):The same logic applies to this one also. when this command is run, given the digits are '644', seting the permission to be "rw-r--r--" which means read and write for the user, read only for both group and other.
chmod 600 (octal):This sets the permission as "rw------" which means read and write for the user and nothing at all for others. :)
chmod -R: Using the -R means appliying the permission change recursively. Meaning it chnages the target folder and every single file and subfolder nested inside it. 
umask:Displays your current mask as a number (e.g., 0022). A mask of 0022 subtracts write permissions from group and others, meaning new folders default to 755 and new files default to 644.
umask -S:Displays the default permission mask in a symbolic, human-readable format (e.g., u=rwx,g=rx,o=rx), showing exactly what access permissions new items will inherit.
stat -c '%A %U %G':This  command Extracts and formats specific metadata or all the metadata specified for an item, cutting out the rest of the text. '%A'prints the permissions in human-readable string format like drwxr-xr-x. '%U'prints the username of th owner while '%G' prints the group name. An example of how the output will be like is "-rw-r--r-- ubuntu developers".
