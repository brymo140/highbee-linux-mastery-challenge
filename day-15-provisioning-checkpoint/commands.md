id <user>: This command let's you to get the speific identity metrics of another user account without needing to switch into their profile. (e.g., id ibrahim). It prints their numeric User ID (UID), primary Group ID  (GID), and all suplementary groups they belong to. 
getent passwd <user>: It queries the system configuration database to isolate and display exactly one user's registration line by printing their home directory path, user's ID, and default login shell in a single clean string.
useradd -m -G: This is the command that is used to spin up a fully provisioned new user. It creates their home directory in details and instantly append them to a comma seperated list of secondary groups all at once.
passwd <user>: When run with the administrative privileges (sudo), it allows you to immediately set or reset the password for that specific user without the system to ask you to input the old password first.
apt list --installed: This installed a complete, searchable list of every single software package currently installed on your Debian/Ubuntu system, along with its version number and architecture.
apt list --upgradable: This command is the one that prints out only the installed packages that currently have a newer version waiting to be downloaded in the online repositories. "sudo apt update" will make sure the data is accurate.
apt update && apt install -y: This is an administrative shortcut stringing commands together. "apt update" will check for newest version of the packages that are currently installed in your machine while "apt install" installs the packages. They are two different commands but the double and sign ties both together and '-y' will automaticaly answer yes to the confirmation prompt that ask if you want to use up space. A specific package can be said after it do it will terget the specified package.  
dpkg -l | grep: This is used to search for a specific package if it is installed or not. (E.g., dpkg -l | grep python) will only show the installed packages containing the word 'python'.
apt autoremove: This command will do a full sweep of your system and look for packages that doest have any more purpose in the machine. Maybe when you have long deleted a program it supposers and it is sitting in the storage doing nothing, this command will delete it.
history: It dumps your current terminal session's command history file onto the screen as a numbered list. It lets you quickly look back at what you typed earlier so you can copy, paste, or modify past commands.
