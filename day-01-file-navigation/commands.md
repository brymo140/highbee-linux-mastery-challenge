pwd: it shows the path of the current working directory a sit full meaning says "print working directory".
ls: it lists out the files in the current folder.
ls -l: it is used to list the detailed information of all files in a directory like the date, file permission etc.  
ls -a: it is used to list all files including the hidden files.
ls -la: This is the combination of 'ls -l' and 'ls -a' which means it lists out all the files inclusing the hidden ones in details. 
ls -lh: it is almost the same as 'ls -l'
cd <absolute path>: the asolute path will contain the directory path the user want to go after 'cd' and it will land them into the idrectory or folder at once without typing cd with the nxt directory name multiople time. eg. "cd user/document/mybook/subjects/"
cd ..: This takes the user a folder-step backward.
cd ~: this takes the user back to the main home directory of the user's account. 
cd -: this takes the user a step back also like 'cd..' but makes go a step back no matter the decision you made.
