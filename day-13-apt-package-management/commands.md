apt update:This command refreshes the background checklist of the system. It only talks to the internet repositories to see if newer versions of your software are available. 
apt upgrade: This is the command that installs the newest available versions of all the currently installed packages based on that checklist.
apt full-upgrade:In addition to updating software, it can smoothly handle changing system dependencies.It will install new required system components or delete old and conflicting software if needed so that it can complete a major operating system update.
apt install:This command installs a specified sofware package along with all other ackground tools like the dependencies it needs to run properly. (e.g., sudo apt install curl) 
apt remove:This one uninstalls the software inaries and executeales, but leaves behind its configuration files. 
apt purge: This is the one that completely wipes out the software and all of its configuration files from the system while leaving no trace behind.
apt autoremove:Cleans up leftover "orphan" packages. When you install a program, it often brings in extra helper packages. If you later delete that main program, those helpers are left sitting on your drive doing nothing. Running this command safely sweeps them all away to free up disk space.
apt search (keyword): It searches the online database for software matching your terms and then prints a list of package names and short description of them. (e.g., apt search text editor)
apt show:This command is used to get the detailed breakdown of a specific package before you download it. it will shwo the version, size, dveloper, homepage, and what other software it needs to work. 
dpkg -l / dpkg -L: While "apt" is the smart tool that talks to the internet, "dpkg" which is a debian package is the low level utility that  physically manages individual files on your hard drive. So, "dpkg" lists every single software package currently installed on your computer, along with its version number and a brief description while "dpkg -L" shows you a complete list of every physical file and folder path that a specific package installed onto your system. It lets you see exactly where a program's configuration files, binaries, and manuals are hiding.
