## What I practiced
I practiced using the commands that represent the standard protocol for secure remote server administration and data transfer over the internet using SSH (Secure Shell). They allow you to securely log into remote machines, generate cryptographic keys, copy files efficiently, and lock down your server against unauthorized access.
