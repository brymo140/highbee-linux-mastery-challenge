tree: It shows a structural map of the current directory using grapical branch lines. it lists all folders and nested subfolders down to the very bottom level.
tree -L: This command is used to limit the graphical tree structure display to a maximum number of levels. An example is "tree -l 2" wich means to only show the current folder and its immediate subfolders, preveting the screen from being flooded.
ln: This command create a hard link to a file in the same hard drive on the computer. Both files share the same storage data that if the original file is deleted, the hard link would still work perfectly as the original one. 
ln -s:This command creates a symbiotic link to a file to form like a shortcut or nickname for the file. it points directly to the path name of the original file or folder but if the original file is moved or deleted, the symbiotic link will break. As noticed, symbiotic links can point to folders and work accross different drives.
readlink:This allows us to read a symbiotic link file and print out the target destination that the shurtcut is pointing to.
realpath: This command converts any relative, symbolic, or messy file path into its clean pathname.
basename:This command strips away the leading directory paths and isolates just the final file name or folder name. Example is running basename /var/log/apt/history.log and the output will be history.log. The use for this is that in case the path is very long and we cannot determine the file the path is leading to or if we are not even looking for a file but a folder. The path may be long and we cant see the folder we are finding with just a look, we just use 'basename <path>' to get the file we want. 
dirname:This command does the opposite of wjat basename does. It strips away the final file name and returns only the leading directory path. Example is running 'dirname /var/log/apt/history.log and it will return /var/log/apt/.
pushd/popd:These two commands are twins that acs like a browser's history or a breadcrumb stack. what they do is that: 'pushd' which i guess means push directory will  push us into any directory we placed at its front like a teleporter and 'popd' will teleport you back to wherever you came from or wherever you started were when you used the 'pushd'. wonderful :)
