## What surprised me
When i was inspecting /var/log/apt/history.log, i noticed that there are plenty of lines as it was listed to me when i ran 'cat' but when i ran 'head' it pasted the exact amount of contents as when i ran 'cat' so began to wonder what happend, but i later know what happened after i ran 'wc' or 'wc -l' cause it shows me that it has 5 lines. That is when i came to the conclusion that the contents of the file can be plenty on the terminal when you cat it but it doesn't assure the amount of lines it has until you run 'wc' or 'wc -l'.
