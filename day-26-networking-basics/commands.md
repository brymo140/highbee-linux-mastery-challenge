- ip a: Short for ip address. It lists every network interface card (like Ethernet or Wi-Fi) connected to your machine, along with their assigned local and public IP addresses (IPv4 and IPv6) and MAC addresses.
- ip route: This command shows the system's internal routing tale. It shows exactly how network traffic traveles out of the computer and also identifies the default gateway (0.0.0.0).
- ping -c: This command sends echo packets to a remote server (like ping -c 4 google.com) to check if it is awake and responsive. The -c 4 flag tells it to stop automatically after excatly 4 attempts, preventing it from looping forever.
- curl (URL): This is a powerful tool to transfer data from or to a server. When run normally (e.g., curl https://example.com), it will download and dump the raw HTML or API data of a webpage directly onto he terminal. 
- curl -I (URL): It feteches only the HTTP header response from a web server instead of downloading the whole page. This lets you inspect server metadata, status code (like 200 ok or 404 Not Found), encryption certificates, and server software types.
- wget (URL): This command is desined primarily for downloading files from the internet. Wget cleanly downloads the target file (like a software installer, image, or zip archive) and saves it directly onto your haed drive unlike  curl which prints text to the terminal. 
- netstat -tulnp: This is a traditional tool to list open ports. The flags stand for: -t (TCP), -u (UDP), -l (listening ports), -n (show numerical addresses instead of names), and -p (show the program name and PID).
- ss -tulnp: The modern, significantly faster replacement for netstat. It uses the exact same flags (-tulnp) and outputs an identical layout, showing you exactly which services (like Nginx on port 80 or SSH on port 22) are open to the network.
- hostname: This one just prints the simple, local network name of your computer.
- hostnamectl: This is the modern tool that provides a highly detailed profile of the machine's identity. It shows the pretty hostname, deployment environment, underlying operating system version, Linux kernel version, and computer architecture (e.g., x86_64 or arm64). You can also use it to permanently change your computer's name (e.g., sudo hostnamectl set-hostname new-server).
