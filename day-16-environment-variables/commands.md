printenv: This command prints a comprehensive list of all current exported environments variables on the system along with their current values. It basically means it will print the path to the current directory of all the environment variables on the system.
env: This is somehow identically to "printenv" when run without arguments, displaying your current environment variebales.  
printenv HOME: This command will isolate and display the value of exactly one specific environment variable. In this case which has the HOME variable, it will prin the path to the your current user's home directory (e.g., /home/ubuntu)
source: This is the one that reads and executes the contents of a configuration text file like "~/.bashrc" immediately inside your current terminal session. It is commonly used to apply newly added variables or shortcuts without closing and restarting your window. 
echo $VAR: Prints the value of any shell or environment variable to your screen. The $ symbol is the crucial key—it tells the terminal to evaluate the text as a variable name rather than printing the literal letters "VAR".
echo $PATH: Displays one of the most critical variables on your computer. $PATH is a colon-separated list of folder directories. Whenever you type a command (like ls or mkdir), your system searches through these exact folders from left to right to find the executable file.
export VAR="value": It creates a new environment variable or overwrites an existing one and make it available to the current shell and any sub-processes or applications yiu launch from this terminal session. 
export PATH=$PATH: This command will append a new directory to your existing execution ##$PATH##. By placing ##$PATH## right after intact while tackling your new folder path onto the very end of the list. 
unset: This will completely delete a variable from the current shel session's memory, wiping its value. 
cat /etc/environment:This one wil show the contents of the system-wide environment configuration file. Unlike shell script files, this file contains pure "KEY="VALUE" pairs and establishes the default environment variables loaded for every single user on the machine at startup.
