## What I practiced
I practiced to handle environment varaibles in linux. What are environment variables? Environment variables are system-wide key-value shortcuts that store configurations settings, paths to the system tools, and user preferences that programs need tp reference behind the scenes.
## What surprised me
The main thing that surprised me is the fact that i discovered how linux works when you run "ls or mkdir", it searches through the system PATH from from the beginning to the end o the PATH. This can be obvious in a scenece that if you are searching for something in the house, you will start from the door closer to you but it i still surprising to discover the way it works exactly.
