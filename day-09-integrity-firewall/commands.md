md5sum: This command is used to check a file if it's not tampered with from where it was deleivered. It calculates a cryptographic hashes (128-bit) of a file. It is commonly used to check for accidental file corruption during download or for security check for a file. Although MD5 (Message Digest 5) is an older obsolete algorith that is no longer safe for security purposes.
sha256sum: This one is also almost the same with MD5 but it calculates a SHA-256 (256-bit) cryptigraphic hashes of a file. This is modern, highly secure industry standard used to verify software downloads and ensure files have not been maliciously altered. Although, this may be slow but it is the most secure way to go with it. 
gpg --gen-key: thse GPGs (GNU Privacy Guard) uses public-key cryptography so, when you share your public key with the world, people can encrypt files for you but only you can decrypt them using your private key. now this commmand "gpg --gen-key" launches an interactive prompt to generate a brand new cryptographic keypair associated with the user name and email address.
gpg --encrypt:This command is obviously used to encrypt a file so that only the specified recipient that has the pulic key can read it. It outputs a secure .gpg binary file.An Example of how to write this exactly is  (gpg -e -r lawalibrahiakorede@gmail.com file1.sh)
gpg --decrypt: This command obviously decrypts an encrypted file using your own secret key and displays or saves the original data.
chattr +i: This command sets the immutable attribute on a file. Once set, the file cannot be modified, written to, deleted, renamed, or linked to by any user on the system—including root. This is excellent for protecting critical system logs or configuration files from accidental deletion or malware tampering. (To remove it, use chattr -i). (e.g., chattr +i file.sh)
lsattr: This command will list the special filesystem attributes of files and folders, allowing you to see if flags like immitability (i) are currently active. (e.g., lsattr file.sh)
ufw enable:UFW is a user-friendly frontend for managing netfilter/iptables firewall rules in Linux. This command then turns on the firewall. It immediately starts enforcing rules, typically blocking all incoming connection attempts while allowing all outgoing traffic by default.
ufw allow <port/service>: This command creates a firewall exception to  permit income traffic. The port number or service name can be specified (e.g., "sudo ufw allow 22" or "sudo ufw allow ssh" which openes up the system for secure shell access)
ufw status: This command displays whether a filrewall is active or not, alongside a clean table showing all curren incoming traffic rules and allowed port.
