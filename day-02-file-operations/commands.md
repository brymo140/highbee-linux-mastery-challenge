mkdir: This one is used to make a directory. 
mkdir -p: This command used to make an enitre nested pathways all at once. The '-P' at the front mean path make both means 'make directory pathways'.
touch: This is used to create a blank enpty file. e.g "touch commands.md".
cp: This command copies a file from a source and paste it in the dpecified destination. E.g "cp commands.md downloads"
cp -r: This is used to copy an entire folder from its source to the specified destination along with everything inside it. e.g. "cp -r day-2-file-operations day-2-copied-folder". The -r means recursive which allows linux to notice that the user is going to be copying a folder.
mv:This is used to move a file or a folder from their current place to a new destination.
rm: This is used to permanently delete a file.
rm -r: This command permanently deletes an entire folder and all of its contents recursively.
rm -rf: This is also used for permanent deletion of a folder and everything inside it without asking for permission. so it recursively and forcibly deletes folders and evruthing inside forever. In '-rf' r means recursive while 'f' means force.
rmdir:This command is a smart one that will check the files that was supposed to be deleted if ONLY there is no contents inside and fails when it contains any files.
