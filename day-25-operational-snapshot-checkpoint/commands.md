- ps aux | grep: The classic administrative pipeline used to quickly search for a running process. ps aux prints out every program in memory, and grep filters out the noise to show you exactly if and how your target program is executing (e.g., ps aux | grep nginx).
- systemctl status <svc>: Generates an immediate health summary for a specific systemd background service. It reveals whether the application is running, its process ID, its current memory usage, and lists its most recent log entries.
- journalctl -u <svc> --since today: Isolates the system log ledger to display only the event logs for a specific service generated since midnight of the current day. This is perfect for cutting out old historical data when an app suddenly breaks down mid-day.
- kill -0 (liveness check): A highly effective liveness check. It doesn't actually kill or send a disruptive signal to the target process. Instead, it asks the kernel: "Does this Process ID actually exist, and do I have permission to talk to it?" If the command succeeds silently, the process is alive; if it returns an error, the process is dead.
- uptime:  Prints a quick, one-line summary of the machine's current status: the exact current time, how long the server has been powered on without a reboot, the number of users logged in, and the System Load Averages over the last 1, 5, and 15 minutes.
- free -h: Displays a clean, human-readable (-h) table showing the system's overall RAM and Swap memory utilization, revealing exactly how much memory is total, used, free, and cached by the kernel.
- vmstat: Stands for Virtual Memory Statistics. It prints a real-time summary row detailing system memory, processes, paging, block I/O, storage activity, and CPU breakdowns. It is incredible for spotting if your system is choking on resource limits.
- iostat: Stands for Input/Output Statistics. It monitors system storage devices and partitions, printing exactly how fast your hard drives or solid-state drives are reading and writing data, helping you diagnose disk performance bottlenecks. (Must be installed via sysstat on some systems).
- watch: Runs any terminal command repeatedly every 2 seconds in a dedicated fullscreen display, automatically highlighting changes over time. Example: watch free -h turns a stagnant memory check into a live, real-time memory monitor. (Press Ctrl + C to exit).
- crontab -e/crontab -l: Interacts with the Cron system, the background time-based task scheduler in Linux. crontab -e: Opens your personal automation schedule file inside a text editor, allowing you to add, edit, or remove time-scheduled rules (e.g., setting a backup script to run every single night at 2:00 AM). crontab -l: Lists out all your currently scheduled cron tasks on your terminal screen without opening the editor.
