useradd: This command is used to create a low level user account. It creates the user account without a home directory or a proper login shell which means they won't be able to log in normally.
useradd -m: This command that has "-m" tells the system to explicitly create a home directory (-m) for the new user and copy default configuration skeleton files like (.bashrc) into it. (e.g., useradd -m username).
useradd -m -s <shell> <username>: It creates the home directory and sets the user's default login shell. For example, "sudo useradd -m -s /bin/bash ibrahim".
adduser: This command is an interactive, user-friendly frontend script that ists on top of the low-level 'useradd' command. Instead of the requirement to memorize falgs, it will walk you through a step by step prompt asking for a password, full name, and room number. It will automaticaly build the home directory and set up a default shell. ("adduser ibrahim" or add "sudo")
passwd: This command is used especially for for a newly created accounts via "useradd". The account will be locked untill a password is assigned so running "sudo passwd ibrahim" allows an administrator to set or reset Ibrahim's password so they can login for the first time.
usermod -aG: This command adds a user to a supplementary group (the -a stands for append, and -G specifies the group). Crucial warning: Always include the -a flag. If you run usermod -G without the -a, you will accidentally wipe out all of that user's other group memberships! (e.g., sudo usermod -aG sudo alex gives Alex administrative access).
usermod -s: Changes the default login shell for an existing user (e.g., switching a user from standard sh /bin/sh to zsh /bin/zsh) -> ("usermod -s /bin/zsh ibrahim").
usermod -l: Changes the login name (username) of an existing user. It renames the account but keeps their numeric User ID (UID) and files intact. Note that you usually have to manually rename their home directory afterward if desired. ("useradd -l highbee ibrahim").
userdel: This command deletes the user account from the system system files (/etc/passwd), but leaves all of their personal files and home directory completely untouched on the hard drive.
userdel -r: Deletes the user account and recursively (-r) purges their entire home directory and mail spool from the system. It is best adviced to use this with caution, as it permanently wipes out all files owned by that user.
